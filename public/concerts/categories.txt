================================================================================
WAYFER API CURL COMMANDS - VENDOR MUSIC CATEGORIES LIST
Base URL: http://localhost:5000/api/vendor
================================================================================

All endpoints require a Bearer token of an authenticated vendor:
Header:
Authorization: Bearer YOUR_VENDOR_TOKEN

Vendors use these read-only category endpoints to populate concert music category/genre
dropdowns, pickers, and filter pills during concert creation and editing.

================================================================================
1. LIST ACTIVE MUSIC CATEGORIES
--------------------------------------------------------------------------------
curl -X GET "http://localhost:5000/api/vendor/concerts/categories" \
  -H "Authorization: Bearer YOUR_VENDOR_TOKEN"

# Query parameters supported:
# - search: Filter by keyword (e.g. ?search=rock)
# - limit: Limit count (default 100)

PowerShell:
Invoke-RestMethod -Uri "http://localhost:5000/api/vendor/concerts/categories" -Method Get -Headers @{"Authorization"="Bearer YOUR_VENDOR_TOKEN"}

2. GET ACTIVE MUSIC CATEGORY BY ID OR SLUG
--------------------------------------------------------------------------------
# By numeric ID:
curl -X GET "http://localhost:5000/api/vendor/concerts/categories/1" \
  -H "Authorization: Bearer YOUR_VENDOR_TOKEN"

# By slug:
curl -X GET "http://localhost:5000/api/vendor/concerts/categories/edm-electronic" \
  -H "Authorization: Bearer YOUR_VENDOR_TOKEN"

PowerShell:
Invoke-RestMethod -Uri "http://localhost:5000/api/vendor/concerts/categories/1" -Method Get -Headers @{"Authorization"="Bearer YOUR_VENDOR_TOKEN"}
