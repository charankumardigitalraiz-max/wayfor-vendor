================================================================================
WAYFER API CURL COMMANDS - VENDOR AUTHENTICATION
Base URL: http://localhost:5000/api/vendor/auth
================================================================================

================================================================================
1. VENDOR REGISTER (Self Onboarding)
--------------------------------------------------------------------------------
curl -X POST "http://localhost:5000/api/vendor/auth/register" \
  -H "Content-Type: application/json" \
  -d '{
    "name": "Metro Travels",
    "businessName": "Metro Mobility Solutions Pvt Ltd",
    "email": "vendor@metromobility.com",
    "phone": "+919876543210",
    "password": "Password@123",
    "address": {
      "street": "Plot 42, Hitec City",
      "city": "Hyderabad",
      "state": "Telangana",
      "country": "India",
      "postalCode": "500081"
    },
    "bankDetails": {
      "accountHolderName": "Metro Mobility Solutions Pvt Ltd",
      "accountNumber": "987654321012",
      "ifscCode": "HDFC0001234",
      "bankName": "HDFC Bank"
    },
    "documents": {
      "panNumber": "ABCDE1234F",
      "gstNumber": "36ABCDE1234F1Z5"
    }
  }'

PowerShell:
$body = @{
  name = "Metro Travels"
  businessName = "Metro Mobility Solutions Pvt Ltd"
  email = "vendor@metromobility.com"
  phone = "+919876543210"
  password = "Password@123"
  address = @{
    street = "Plot 42, Hitec City"
    city = "Hyderabad"
    state = "Telangana"
    country = "India"
    postalCode = "500081"
  }
  bankDetails = @{
    accountHolderName = "Metro Mobility Solutions Pvt Ltd"
    accountNumber = "987654321012"
    ifscCode = "HDFC0001234"
    bankName = "HDFC Bank"
  }
} | ConvertTo-Json -Depth 5

Invoke-RestMethod -Uri "http://localhost:5000/api/vendor/auth/register" -Method Post -Headers @{"Content-Type"="application/json"} -Body $body

4. UPDATE VENDOR PROFILE
--------------------------------------------------------------------------------

  -H "Authorization: Bearer YOUR_VENDOR_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "businessName": "Metro Mobility Global Pvt Ltd",
    "address": {
      "street": "Plot 55, Cyber Towers",
      "city": "Hyderabad",
      "state": "Telangana",
      "country": "India",
      "postalCode": "500081"
    }
  }'

PowerShell:
$body = @{
  businessName = "Metro Mobility Global Pvt Ltd"
  address = @{
    street = "Plot 55, Cyber Towers"
    city = "Hyderabad"
    state = "Telangana"
    country = "India"
    postalCode = "500081"
  }
} | ConvertTo-Json -Depth 5

Invoke-RestMethod -Uri "http://localhost:5000/api/vendor/auth/profile" -Method Patch -Headers @{"Authorization"="Bearer YOUR_VENDOR_TOKEN"; "Content-Type"="application/json"} -Body $body

Sample Response (200 OK):
{
  "status": "success",
  "message": "Vendor profile updated successfully.",

5. CHANGE PASSWORD
--------------------------------------------------------------------------------
curl -X POST "http://localhost:5000/api/vendor/auth/change-password" \
  -H "Authorization: Bearer YOUR_VENDOR_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "currentPassword": "Password@123",
    "newPassword": "NewPassword@123"
  }'

PowerShell:
$body = @{
  currentPassword = "Password@123"
  newPassword = "NewPassword@123"
} | ConvertTo-Json

Invoke-RestMethod -Uri "http://localhost:5000/api/vendor/auth/change-password" -Method Post -Headers @{"Authorization"="Bearer YOUR_VENDOR_TOKEN"; "Content-Type"="application/json"} -Body $body

Sample Response (200 OK):
{
  "status": "success",
  "message": "Password changed successfully"
}

8. REFRESH ACCESS TOKEN
--------------------------------------------------------------------------------
curl -X POST "http://localhost:5000/api/vendor/auth/refresh-token" \
  -H "Content-Type: application/json" \
  -d '{
    "refreshToken": "YOUR_REFRESH_TOKEN"
  }'

PowerShell:

Invoke-RestMethod -Uri "http://localhost:5000/api/vendor/auth/refresh-token" -Method Post -Headers @{"Content-Type"="application/json"} -Body $body
